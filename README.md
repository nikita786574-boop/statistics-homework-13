## task 1

Затраты на развитие производства x и y величина годовой прибыли в течение 3 лет представлены следующей таблицей: $x_1 = 7, y_1 = 30, x_2 = 5, y_2 = 30, x_3 = 10, y_3 = 42$. На основе метода наименьших квадратов спрогнозировать величину годовой прибыли, если затраты на развитие производства составили x = 3.

### solution

Формула для метода наименьших квадратов берётся из минимизации суммы квадратов остатков (функции ошибки).

$$\hat{y} = b_0 + b_1 \cdot x_1$$

Коэффициент наклона $b_1$

$$b_1 = \frac{\sum(x_i-\overline{x})\cdot(y_i - \overline{y})}{\sum{(x_i-\overline{x})}^2}$$

Свободный член $b_0$

$$b_0 = \overline{y} - b_1 \cdot\overline{x}$$

$$b_1=2.5263$$

$$b_0=15.4737 $$

## task 2

Станок - автомат штампует валики. По выборке объема $n=100$ вычислине выборочное среднее диаметров изготовленных валиков. Найти с надёжностью $0.95$ точность $\delta$, с которой выборочное среднее оценивает математическое ожидание диаметров изготовляемых валиков, зная, что среднее квадратическое отклонение $\sigma = 2мм$. Предполагается, что диаметры валиков распределены нормально.

### solution

Мы извлекаем выборку из нормального распределения.

Среднеквадратическое отклонение известно, поэтому 

$$\overline{x} - \frac{\sigma}{\sqrt{n}}\cdot u_{кр} < a < \overline{x} + \frac{\sigma}{\sqrt{n}}\cdot u_{кр}$$

где 

$$\Phi_o(u_{кр})=\frac{\gamma}{2} (\gamma - надёжность)$$

Для $\gamma = 0.95$, $u_{кр} = 1.96$

Точность $\delta=\frac{\sigma}{\sqrt{n}}\cdot u_{кр} = \frac{0.2}{\sqrt{100}}\cdot1.96 = 0.0392$


С вероятностью $\gamma =0.95$ выборочное среднее генеральной совокупность $a$ лежит в интервале 

$$[\overline{x}-0.0392; \overline{x}+0.0392]$$

точность $\delta = 0.0392$



## task3

Среднее время сборки изделия было 90 мин. Инженер изобрёл новый метод сборки изделия. При испытаниях времена сборки 10 изделий новым способом составили: 79, 74, 112, 95, 83, 96, 77, 84, 70, 90 (мин). Построить доверительный интервал для нового среднего времени сборки с надёжностью 95%

### solution

Нам неизвестна дисперсия генеральной совокупности. Будем пользоваться тем, что выборка распределена по t-распределению со средним в такой интервале

$$\overline{x}-\frac{s}{\sqrt{n}}\cdot t <a <\overline{x}+\frac{s}{\sqrt{n}}\cdot t $$

Где 

$s^2$ - исправленная выборочная дисперсия.

$t=t_{двуст}(\alpha, n-1), \alpha = 1-\gamma$

$$t_{двуст}(0.05, 9)=2.26$$

$$\delta = 8.9644$$

Среднее генеральной совокупности лежит в интервале $[\overline{x} - 8.9644; \overline{x}+8.9644]$ с вероятностью 95%.


## task4

При измерении веса 20 шоколадных батончиков получены выборочное среднее
50,01 г и выборочное среднее квадратическое отклонение 1,02 г. Найти доверительный
интервал для среднего веса с надежностью 95%

### solution

Та же задача, что и 3, только теперь не дана выборка, а даны её параметры

$$\overline{x}-\frac{s}{\sqrt{n}}\cdot t <a <\overline{x}+\frac{s}{\sqrt{n}}\cdot t $$

$t_{двустороннее}(0.05, 19) = 2.09$

$$\delta = 0.4767$$

Среднее генеральной совокупности лежит в интервале $[49.5333:50.4867]$
